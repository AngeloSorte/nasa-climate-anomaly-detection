# NASA Climate Anomaly Detection

## Description
Detection of climate anomalies from NASA GISS data using Isolation Forest. The project identifies abnormal temperatures over time, visualizes the anomalies, and provides interpretable insights into global climate variations.

## Objective
This project aims to automatically identify periods of anomalous temperature in the NASA GISS global dataset. The goal is to create an interpretable model that can help monitor significant climate variations and provide immediate visual insights.

## Dataset
- Source: NASA GISS Surface Temperature Analysis (GISTEMP)
- Link: https://data.giss.nasa.gov/gistemp/
- Contains global monthly mean temperatures from the past to the present.

## Method
- Data cleaning and transformation
- Feature engineering (continuous temporal index)
- Application of Isolation Forest (unsupervised ML) to detect anomalies
- Graphical visualization with anomalies highlighted

## Results
The model highlights temperature anomalies over time in red. The graphs show anomalous variations that could be related to significant weather events.
